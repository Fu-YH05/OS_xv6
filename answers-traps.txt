1. 哪些寄存器保存函数参数？例如，在 main 对 printf 的调用中，哪个寄存器保存 13？

   a0~a7 保存前八个函数参数（更多参数通过栈传递）。在 main 调用
   printf("%d %d\n", f(8)+1, 13) 时，格式串在 a0，数值 12 在 a1，
   13 在 a2。

2. main 的汇编代码中对函数 f 的调用在哪里？对 g 的调用在哪里？
   （提示：编译器可能会内联函数。）

   main 的汇编中不存在对 f 或 g 的调用：编译器将两个函数都内联了，
   并在编译期算出 f(8)+1 = 12。main 的汇编中对应参数只有一条
   "li a1, 12"。

3. 函数 printf 位于哪个地址？

   0x630（见 user/call.asm）。

4. 在 main 中 jalr 调用 printf 之后，寄存器 ra 的值是什么？

   0x38。jalr 会把下一条指令的地址写入 ra；位于 0x34 的 jalr 后面
   紧跟着 "38: li a0,0"。

5. 运行以下代码。

       unsigned int i = 0x00646c72;
       printf("H%x Wo%s", 57616, &i);

   输出是什么？如果 RISC-V 是大端序，为了得到相同的输出，应把 i
   设置为什么？是否需要把 57616 改成其他值？

   输出为 "HE110 World"。57616 的十六进制是 0xe110（"E110"）。
   i = 0x00646c72 按小端序存储在内存中，字节依次为 72 6c 64 00，
   即 ASCII 字符 "rld\0"。合起来就是 H + E110 + Wo + rld。

   若为大端序，应设置 i = 0x726c6400。57616 无需改变：它按数值
   打印，而不是按字符序列打印。

6. 下面的代码在 'y=' 之后会打印什么？（注意：答案不是一个具体的
   值。）为什么会这样？

       printf("x=%d y=%d", 3);

   一个不确定的值。格式串声明了两个 %d 参数，但调用方只提供了一个，
   于是 printf 会从寄存器 a2 读取"缺失"的第二个参数，其内容是调用方
   残留在那里的任意值。这是未定义行为。
